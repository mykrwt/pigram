# Frequently Asked Questions

## What is Pigram?

Pigram is an open-source Android patch for Instagram that keeps direct messages, the home feed, stories, profiles, search and notifications while offering controls for feed visibility, Reels, Explore, ads and recommendations.

## Is Pigram affiliated with Instagram or Meta?

No. Pigram is an unofficial community project and is not affiliated with Instagram or Meta.

## Does Pigram collect my password?

No. Pigram does not collect, store, proxy, or transmit your credentials.

Instagram login still happens through the Instagram app itself.

## Can I build it myself?

Yes. Users are encouraged to build the APK themselves using the documented patching process.

## Why does Android warn me before installing the APK?

Pigram is distributed outside the Google Play Store, so Android may show warnings before installation. This is expected for APKs installed manually.

Only install APKs from the Pigram releases on the project GitHub repository, or build the APK yourself.

## Classic APK or Clone APK?

The classic APK replaces the regular Instagram app because it keeps Instagram's original package ID.

The clone APK is designed to install alongside the regular Instagram app by using a different package ID.

Use the clone APK if you want to keep the official Instagram app installed at the same time.

## Can my Instagram account be banned?

Pigram is unofficial and modifies the Instagram Android app. This may violate Instagram's terms of service. Use it at your own risk.

## Why not use a WebView wrapper?

Pigram patches the real Android Instagram app instead of wrapping the website in a WebView. This allows it to keep the native app experience while removing specific distracting features.

## Why not use an accessibility-service blocker?

Accessibility blockers usually react to the interface after it appears. Pigram aims to remove or block distracting parts more directly through patches.

## Does Pigram remove all distractions?

The goal is to remove the most addictive parts while keeping useful social features. Some features may change or break when Instagram updates its app.
