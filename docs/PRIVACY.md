# Privacy

Pigram is an Instagram Android patch that adds optional distraction controls. Private messages continue to be handled by Instagram and are not stored or proxied by Pigram.

## Data collection

Pigram itself does not collect analytics, credentials, personal data, or usage data.

The GitHub Pages site does not load third-party analytics scripts.

## Credentials

Pigram does not collect, store, proxy, or transmit Instagram usernames, passwords, or session tokens.

Authentication is handled by Instagram inside the app.

## Network behavior

Pigram may block or modify some Instagram app behavior depending on the active patches.

Where possible, patches related to ads, telemetry, or network behavior should be documented. The README documents the current blocked network paths.

## Third parties

Pigram is not affiliated with Instagram, Meta, Facebook, or any third party.

## Recommendation

If you do not want to trust a prebuilt APK, build Pigram yourself from source.
